Execution hosts

Укажи URL ComfyUI-инстанса. Для локального запуска используй http://127.0.0.1:8188.

S3

Поля предзаполняются из env и дефолтов раннера. Bucket берётся из `S3_BUCKET`, а если его нет — из `S3_MODELS_BASE` или `S3_NODES_BASE`. Если bucket указан, каждая картинка/манифест автоматически зеркалируются в S3. Креды берутся из env (AWS_*) или из стандартного boto3-lookup.

Память (RAM-чистка ComfyUI)

Каждые N завершённых джоб раннер дёргает ComfyUI POST /free — сбрасывает кэши, чтобы длинные батчи (сотни генераций) не выжирали ОЗУ пода до OOM.
